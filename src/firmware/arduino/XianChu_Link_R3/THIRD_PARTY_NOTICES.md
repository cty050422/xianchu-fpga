# Display resources

Chinese glyphs are the XianChu UI glyph subset derived from Noto Sans CJK SC under SIL OFL 1.1. See the repository's `third_party/fonts/` directory for the license, pinned source and regeneration command.

The classic 5x7 ASCII glyph data in `performance_glyphs.h` is from Adafruit GFX Library's `glcdfont.c`. Its original BSD license and copyright notice are retained in `Adafruit_GFX_LICENSE.txt`.

Adafruit GFX, SSD1306, BusIO and the Espressif Arduino core remain external dependencies with their respective licenses.
