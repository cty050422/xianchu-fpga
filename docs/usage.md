# 演奏与手机操作

## 上电与校准

1. 按 [硬件表](hardware.md) 接线，FPGA 与 S3 各自供电并共地；连接有源音箱与 HDMI 显示器。
2. 松开四片 FSR、两个摇杆回中。按住 **Z2**，点按 FPGA **KEY2**，稍等后松开 Z2，等待校准完成。
3. 按 FSR1–4 检查四区分别响应。松手后声音按所选音色的包络逐渐衰减，不能用尾音是否瞬时消失来判断按键未松开。
4. OLED 等待设备或状态失鲜时，先检查 FPGA→S3 的串口和共地；不要以 BLE 能连接替代串口有效性检查。

## 自由演奏

四区域可同时触发，力度分别控制各声部。四音色为拨弦、吹管、钟声与合成贝斯。

| 操作 | 功能 |
|---|---|
| Z1 单击 | 音组 A/B 切换 |
| Z1 双击 | 原八度 / 高八度切换，高八度频率为原来的两倍 |
| Z2 单击 | 四音色循环切换 |
| Z2 双击 | 自由 → 引导 → 挑战 → 自由 |
| Z2 长按约 1 秒 | 曲谱练习开始、暂停、继续 |
| 同时按两个 Z | 停止并回自由状态 |

音组 A 为 **C4、D4、E4、G4**，音组 B 为 **G4、A4、B4、C5**；高八度各升 12 半音。小程序自定义四区 MIDI 音高后，以设备回报为准；面板切音组回到音组表。音组/八度改变支持正在按住声部的实时改调；松手事件仍匹配正确声部。切换音色主要作用于新触发声部，已持有声部与其尾音保留原音色。

J1 X 做连续滑音；J1 Y 调节颤音深度，颤动由片内 LFO 产生。J2 X 改变谐波分量/明暗；J2 Y 改变当前效果湿度，回中趋向干声。两摇杆的正负方向均是 **X+↓、X−↑、Y+→、Y−←**。OLED 与小程序显示实际轴向、幅度及曲谱提示；没有方向信息的旧曲谱不凭空生成单一方向要求。

## 蓝牙配对与曲谱

1. 手机开启蓝牙，在小程序“演奏 → 连接”扫描并选择 XianChu 设备。
2. 按页面配对/授权操作，手机要求验证码时输入 OLED 显示的六位码。蓝牙 PIN 不等于电脑曲库服务连接码。
3. 验证 FPGA PING；确认实时状态帧与声部数据更新。USB 串口 `ARM` 不能替代手机 BLE 的认证来源。
4. 启动电脑曲库服务（`npm start` / `start_catalog.cmd`）。在“设备”页填电脑局域网地址，默认 `http://电脑IP:8893`，保存并检查连接。
5. 在“曲库”选曲；先查看四区映射/分段结果，再下载曲谱。页面显示逐条应答和最终提交成功后才算设备已接收。
6. “试听”把符号曲谱传给 FPGA 的示范序列器，由 FPGA 实时合成并通过音箱输出。它不是手机录音的蓝牙音频回放。

配套客户端在会话有效时续期授权；断线、失鲜、重启或会话代际改变后重新建立会话，不自动执行旧草稿。若重复要求授权，先确认确实用了同一 Release 的 S3 和客户端，再检查状态流与手机后台限制。

## 三种演奏模式

| 模式 | 推进规则 | 错误处理 |
|---|---|---|
| 自由 | 无曲谱时也可演奏 | 不限制目标区域 |
| 引导 | 等待正确区域、要求的手势与时值条件，再进入下一步 | 错区不触发新音，显示错误，保留目标 |
| 挑战 | FPGA 按曲谱节奏推进 | 统计命中、错按和漏拍 |

没有有效曲谱时不会开始引导/挑战；返回自由演奏或先下载曲谱。切模式/切曲会重建相应练习状态，不混用旧计数。OLED 指明当前模式、音色、音组以及需要的操作；LED1–4 分别对应 FSR1–4。进入引导模式不等于已经点击“开始”。

## 三块显示各看什么

- **OLED**：演奏者近距离查看模式、音色、音组、目标与摇杆方向，中文为主。
- **HDMI**：观众观察 FPGA 数字波形、声部电平、片内 FFT 与同步 XY 图。它观察数字音频节点，不是探头测得的 DAC 模拟波形。
- **浏览器串口台**：可选诊断/导出工具，通过用户点击连接串口；日常演奏不必打开。`npm run monitor` 或 `start_monitor.cmd` 启动。

## 常见问题

| 现象 | 优先检查 |
|---|---|
| 上传提示缺少 `Adafruit_GFX.h` | 在 Arduino 库管理器安装 GFX、SSD1306、BusIO |
| S3 应用超出容量 | 选择 16 MB Flash 与 **3 MB APP** 分区，核对 3145728 bytes 上限 |
| BLE 已连，声部/波形不动 | 先查 FPGA 有效状态帧、UART 交叉连线、共地与固件是否配套 |
| PING 无应答 | 核对手机授权、新鲜 FPGA 状态、同版 S3 与小程序；不要反复发送 USB ARM 混淆来源 |
| 下载中断 | 保留原曲谱；重连后重新下载，未收到最终确认不显示成功 |
| `url not in domain list` | 微信开发预览调试限制；正式使用需 HTTPS 合法域名，浏览器能开不等于微信放行 |
| HDMI 无画面 | 接显示器输入；选择对应输入源；不能接普通笔记本 HDMI 输出口 |
| 声音失真或过小 | 先完成校准，核对正确 FS 与音箱输入；不要通过反复提高增益掩盖供电/模拟问题 |

## 测试模式

持有 Z1 跨 KEY2 复位可进入约 55 Hz 的 32 分量验证模式；该模式用于频谱与片内运算检查，不是正常曲谱演奏。退出后重新校准进入自由模式。统计方法与数据口径见 [测试说明](testing.md)。
