# 边界与已知限制

- 默认乐器是 **4 声部**；每声部的谐波分量不是分别拥有独立 ADSR 的复音键。
- PT8211 是右对齐音频接口；本板输出不能直接宣称标准 Philips I²S。若更换 I²S DAC，需要另做发送器/引脚适配和验证。
- 当前手机产品只有“演奏 / 曲库 / 设备”三页。仓库保留的音频转写、ASR、聊天与录音评分模块属于可选研究代码，**不等于这些功能已集成到当前页面并通过真机验收**。默认曲库服务不启动这些路由，不读取付费 Key。
- 曲谱下载、设备端符号合成试听已经有对应代码路径；手机 PCM 录音传给 FPGA 播放、A2DP 蓝牙音箱、任意商业歌曲在线下载不在当前功能范围。
- 配置 22 个字段中支持 15 个，另外 7 个拒绝；见 [协议表](protocol.md)。
- HDMI 为 640×480 数字仪表画面，不是 1080p 视频输出；屏幕缩放、过扫描与刷新行为需实屏核对。FFT 观察片内数字节点，不代替模拟音频测试。
- 本仓库提供固定目标板的电气接线与原工程约束；没有把历史自制调理板的完整 Gerber、机械 CAD 和未核实孔距伪装成当前可生产硬件资料。
- 微信正式发布需要自己的 AppID、权限声明和 HTTPS 合法域名；本地 HTTP 曲库不是已经部署的公网服务。
- FPGA BSRAM 使用接近上限，增加长延迟效果、缓存或高分辨率显示前必须重新评估布局、资源与时序。

这些限制不妨碍当前四区演奏、手势表情、曲谱练习与数字显示；它们用于明确复现目标，避免把实验支路与默认产品混淆。
